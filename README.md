# VTRANSYS Sales CRM, prototype

A clickable prototype of the sales CRM that Plinthera Technologies is building for VTRANSYS SOLUTIONS, Pune.

Open it at **https://athark20.github.io/vtransys-crm/** and press "Sign in with Microsoft". Sign-in is simulated here; the live CRM will use your Microsoft 365 accounts.

Every customer, contact, quotation, value and person in the prototype is sample data.
